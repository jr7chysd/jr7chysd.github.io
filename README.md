# 导航主页（单页 / 极简 / 黑灰配色）

## 打开方式

双击 `index.html` 即可在浏览器中打开（无需服务器、无需安装）。
想固定成首页：把 `index.html` 拖进浏览器书签栏，或用浏览器"设为首页 / 启动页"。

## 文件说明

| 文件         | 作用                              | 平时需要改吗   |
| ------------ | --------------------------------- | -------------- |
| `data.js`    | **所有链接和分类**都在这里        | ✅ 只改这个    |
| `style.css`  | 配色、字号、间距、每项宽度        | 需要调外观时改 |
| `app.js`     | 渲染逻辑（读 `data.js` 生成页面） | ❌ 不用改      |
| `index.html` | 页面骨架，引入上面三个文件        | ❌ 不用改      |

## 常用维护操作

**新增一个链接** —— 在 `data.js` 找到对应分类，复制一行改掉三个字段：

```js
{ name: '显示文字', url: 'https://example.com', icon: 'fa-solid fa-star' },
```

**图标去哪找** —— <https://fontawesome.com/search?o=r&m=free>
页面用的是 FontAwesome 7.3.1：实心图标写 `fa-solid fa-xxx`，品牌图标写
`fa-brands fa-xxx`（GitHub、OpenAI、Claude、Copilot 等）。

**删除链接 / 删除整个分类** —— 删掉对应的 `{ ... },` 一行，或删掉整个
`{ category: '...', items: [ ... ] },` 段落。

**调整顺序** —— 直接上下移动整行 / 整段即可，页面顺序与文件顺序一致。

**改分类名** —— 改 `category` 后面的文字，例如把 `'Forums'` 改成 `'Tools'`。

**调整每行显示几个 / 松紧** —— 改 `style.css` 顶部的这几个值即可：

| 变量                          | 当前值                 | 作用                       |
| ----------------------------- | ---------------------- | -------------------------- |
| `--max-width`                 | 820px                  | 整页最大宽度               |
| `--col-min`                   | 96 / 100 / 108 / 112px | 单个导航项宽度，按屏幕分档 |
| `--gap-x` / `--gap-y`         | 4px / 8px              | 导航项之间的横 / 纵向间距  |
| `--icon-size` / `--name-size` | 18px / 12px            | 图标 / 文字大小            |
| `--page-top` / `--group-gap`  | 20px / 20px            | 页顶留白 / 分类间距        |

布局本身自适应：手机一行 3 个、平板 5~6 个、宽屏 6 个；嫌紧就把 `--col-min`、
`--gap-x` 调大一点，嫌松就调小。

**换配色** —— 只改 `style.css` 顶部的 `--bg` / `--icon` / `--text` / `--label`。
文件底部还留了一段浅色主题，取消注释即可启用。

**某个图标单独上色** —— 在该条目里加一个字段，例如
`color: '#e0b050'`（仅个别图标用，整体仍是黑灰）。

**离线使用** —— 下载 FontAwesome 7.3.1 免费版，把 `index.html` 里那行 CDN 链接
改成本地的 `all.min.css` 路径（webfonts 目录要一起放好）。

## 设计约定

- 单页面，页面内无标题；分类名只是灰色小字标签。
- 只有 FontAwesome 图标 + 文字，无按钮、无边框、无 hover 与动画。
- 默认黑底灰字，`color-scheme: dark`。
- 分类内部用 `flex` + `flex-wrap` 自适应排版：每项固定宽度、从左侧开始排；
  手机约 3 列，平板 5~6 列，宽屏 6 列。
